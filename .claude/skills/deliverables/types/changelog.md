# Changelog

**Read by:** maintainers and users who want the full list of what changed in a cycle.
**Inputs:** the cycle's deltas (added, changed, removed), the tickets closed in the cycle and the known issues in the verification report.

Every entry cites its source: the delta for a change, the ticket for a fix, the verification report for a known issue.
Recover deltas are omitted: describing existing behavior is not a change users see.

1. **Added** - one entry per delta whose operation is add, saying what is new.
2. **Changed** - one entry per delta whose operation is modify, saying what behaves differently now.
3. **Removed** - one entry per delta whose operation is remove, saying what is gone and what replaces it, if anything.
4. **Fixed** - one entry per ticket closed in the cycle, saying what was wrong and is now right.
5. **Known issues** - the open problems listed in the verification report, each as written there.
