# Technical docs

**Read by:** maintainers and integrators who change or operate the system.
**Inputs:** the architecture, the module contracts, the data model, the integrations and the observability documents.

1. **Overview** - the system in one page and the main decisions behind it.
2. **Architecture** - the parts, their boundaries and how they depend on each other.
3. **Modules** - each module's responsibility and its interface.
4. **Data model** - the entities, their relationships and the rules on them.
5. **Integrations** - the outside systems used and how each failure shows up.
6. **Operations** - how to build, run, observe and recover the system.
7. **Open questions** - spikes and unverified behavior, marked as such.
