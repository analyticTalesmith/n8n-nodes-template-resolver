# Readme

**Read by:** a newcomer deciding whether to use the project and how to start.
**Inputs:** the product vision, the glossary, the built user docs and the current version.

1. **Purpose** - what the project is and the problem it solves, in two sentences.
2. **Who it is for** - the intended users and what they need to know first.
3. **Install** - the steps to get it running, from the user docs.
4. **First use** - the shortest path to a visible result.
5. **Where to go next** - links to the user docs, the technical docs and the changelog.
6. **License** - the license and how to contribute, if the sources state them.
