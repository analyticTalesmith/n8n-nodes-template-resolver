# Brief: test writer for the case matchers card

## Objective and why

Project goal: a deterministic, no-eval template language for prompt assembly, with a headless core and an n8n node as a thin wrapper.
Cycle goal (`language`): authors can shape values, branch, loop, name, declare and reuse prompt fragments in the language itself without leaving the house style or the no-eval core.
Card goal: a CASE branch can match several values, a variable or a comparison (`{{WHEN "a", "b"}}`, `{{WHEN other}}`, `{{WHEN >= 10}}`), so authors stop chaining IF for every choice.
Your objective: turn each criterion into failing table-driven jest tests (`it.each` rows) in `tests/language/case.test.ts`, plus one golden case, that fail for the right reason (an assertion, never a missing import or a syntax error), commit them, and record red evidence. The tests are the oracle the implementer is held to, so each must break on a plausible wrong implementation. Each test name starts with its criterion id (`cs-values`, `cs-var`, `cs-compare`, `cs-errors`, `cs-analyze`).
