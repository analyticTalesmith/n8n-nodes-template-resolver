# Table cells escape pipes and newlines

Any agent picking this up: read the documents linked below, change only the files listed in Scope as a write (add, edit or remove), treat everything else as read-only, and stop and ask when you need more than this ticket gives you.

## Goal and why

<!-- One short paragraph for the model: what must be true when this is done, and why it matters. -->

Table cell content containing a pipe or a newline must not break the markdown table: a pipe is escaped as \| and a newline is flattened to a space, for static rows and for rows generated by FOR, in header and body.


## Must-haves

<!-- The behavior that must hold. A short list, not a requirements document. -->
