# Probe: spike or prototype

Answer one feasibility question cheaply before committing. Name the question and a time box, run a throwaway probe in scratch space that is never merged, and write the findings: the question, the sources, what was found and how confident you are. A question that is not one sentence is split first. A spike never ships code.
